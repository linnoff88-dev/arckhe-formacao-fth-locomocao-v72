Lesson 5 · 16 min

PPO with thousands of robots in parallel

The algorithm that trains almost every humanoid gait today is PPO, running thousands of copies of the robot on the GPU. In this lesson you learn the collect, estimate, and update loop, run a ~120-line PPO with mjlab's values on CPU, with 16 robots, and see the command that does the same with 4,096.

Start the lesson

In this lesson you will

  1. 1The loop: collect 24 steps per robot, estimate the advantage, update the network
  2. 2The G1's hyperparameters in mjlab: lr 1e-3 adaptive, clip 0.2, 5 epochs
  3. 320 iterations on CPU: checkpoint and progresso.csv
  4. 4At scale (shown): 4,096 environments on the GPU, 30,000 iterations

Goal: run a short PPO training on CPU that saves a checkpoint and a log, and read the values from a real training run in mjlab.

05 · Where real training runs

Three current paths, all on the GPU. Click each one.

1. mjlab

Isaac Lab's "manager-based" API on top of MuJoCo Warp 3.16, Apache-2.0, with uv. It requires an NVIDIA GPU (on macOS, evaluation only). It is the closest relative of this kit: the same term names.

2. Isaac Lab

unitree_rl_lab, BeyondMimic and Berkeley Humanoid Lite train on Isaac Lab 2.x (pin the version each README indicates). Isaac Lab 3.0 is in early access (EA, 09/16/2026), requires Isaac Sim 6.1 and a new Python 3.12 environment with uv.

(reported) According to the Isaac Lab benchmark table cited in robotica-real2sim, Isaac Lab's own G1 rough-terrain velocity task, with 4,096 environments, runs about 82 thousand steps/s on an RTX 4090 in 3.0 beta; the number varies with the version.

3. Playground

MuJoCo Playground has the G1JoystickFlatTerrain task, with Python 3.12 + uv, on JAX/MJX; training with MJWarp was announced in beta.

4. Legacy

legged_gym, on top of Isaac Gym (2021), showed that you can train a gait in minutes with thousands of environments. Today it is legacy: the repositories checked by the course use Isaac Lab or mjlab.
